## ข้อสังเกต

1. เมื่อไม่มีมนุษย์ AI เลือก **ทางลดความเสี่ยง** แทบทุกข้อ — มี Devil's Advocate อยู่ในวง และทุกคนต้องหาข้อตกลงร่วม ข้อสรุปจึงไหลไปทางตัดของออก
2. เจ้าของตัดสินต่างเพราะมี **บริบทที่ AI ไม่มี** (เหตุ ransomware เป็นข่าวสาธารณะแล้ว · ตำแหน่ง SVP ตรงกับ LinkedIn)
3. ข้อที่ไม่มีใครเสียผลประโยชน์ (CTA ฟอร์ม · ไม่แสดงอีเมล · disclaimer) ได้คำตอบเดียวกันทั้งสองแบบ
4. นี่คือเหตุผลที่ Lab 02 แยก **DEBATE (ความเห็น)** ออกจาก **DECISIONS (คำตัดสินของคน)** — AI ถกได้ดี แต่ถ้าให้ตัดสินเองทั้งหมด จะได้เว็บที่ปลอดภัยแต่เป็นตัวเจ้าของน้อยลง
